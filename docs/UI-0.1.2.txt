AutoPlay 0.1.2 界面迭代说明
日期：2026-10-31

结论
当前设置页有明显优化空间。0.1.1 使用约 540 CSS 像素宽的右侧抽屉承载全部设置；中文主标签约 19.8 像素、部分说明仅 16.2 像素，夜间模式选项和高级摘要容易被截断。只放大字号会增加滚动，因此本版同时调整信息分组、版面宽度、字体和操作反馈。

本次落实
1. 设置改为全屏工作区，宽屏左侧固定“常用 / 显示 / 连接”，右侧独立滚动；窄屏改为顶部三项导航。完成按钮始终可见。
2. 以 1280×720 CSS 视口为例：主要标签约 24px，说明约 20px，设置标题约 32px；导航按钮高约 72px，下拉框和完成按钮至少约 64px。正文行距 1.45，取消中文标题负字距。手机窄屏采用 18px 根字号，正文约 21.6px。
3. 主要行左右内边距约 20px，区域间约 20–30px；留白用于分组和阅读，不再保留大块无用的半屏背景。
4. 夜间模式选项简为“定时 / 跟随系统 / 始终白天 / 始终夜间”。定时时段独立显示，仅选择“定时”时出现。
5. 画面大小改名“CarPlay 内容大小”，与设置页字号明确区分。内容大小、帧率和应用按钮在显示页靠前；编码、高分辨率、兼容显示、调试收入展开区。
6. 保存结果始终显示在应用按钮下；模态设置打开时把原有错误/提示移入对话框，关闭后移回投屏页。浏览器检测先关闭设置，避免被遮挡。保存期间禁用编码、高分辨率和性能开关，防止与正在保存的请求竞争。
7. 切换语言时同步刷新音频状态和保存反馈，避免残留上一种语言。欢迎页先呈现配对/设置，降低无边框跳转入口的优先级；保留跳转期间画面中断的真实说明。导航音频文案移除网页播放 Siri 的承诺。
8. 保留纯色背景和减少动画偏好，不增加背景模糊、网络字体、图像素材或第三方依赖。投屏几何尺寸、触控坐标和解码路径不因设置页布局而改变。

与 Apple 官方设计思路的关系
Apple CarPlay 人机界面指南强调：驾驶座上便于扫读、减少非必要细节、重要内容与操作靠前、相似功能保持一致，以及在真实车内不同光线下检验可读性。本版遵循这些原则；这是 AutoPlay 网页外层界面，不是使用 CarPlay 原生模板构建的应用，也不意味着获得 Apple 认证。以上 CSS 字号与间距是本项目设计值，不是 Apple 强制规定或物理尺寸/ISO 认证。

实际 CarPlay 画面如何调整
CarPlay 内部文字、应用图标、Dock 和布局由 iPhone 绘制。网页 CSS 只控制欢迎页、设置与提示。现有 uiScale 通过接收端上报的显示尺寸影响 iPhone 输出密度；本版保留原默认值 85（小），没有修改协议或显示尺寸算法。上车后建议停车比较“小 / 标准 / 大”，选择驾驶座上能轻松读清且不遮挡导航信息的档位。提高分辨率主要改变清晰度，不能代替内容大小调整。无需另画一套假 CarPlay Dock 盖在手机画面上。

验证与证据
- 前端既有 check、check-audio、check-car、check-browser、check-runtime 全部通过；最后一项 10 组运行时回归通过。
- TypeScript 类型检查和 Vite 生产构建通过。构建仍提示 browser-check.js 为普通脚本；这是原有兼容检测入口，构建产物中已确认存在。
- 本机浏览器、本机 HTTP/WebSocket 模拟服务：1280×720、1256×706、960×540、390×844，中文/英文各三页，共 24 种组合。均仅有一个可见设置页，设置容器无横向溢出，投屏容器保持与当前视口同宽同高。
- 操作检查：切换分类、语言切换、定时说明显隐、内容大小/帧率提交与恢复、保存反馈、关闭设置、展开高级、浏览器检测可见性、提示元素在模态层内外归位。仅提交到模拟服务，不代表已调整真实设备。
- 浏览器测试完成时未捕获 JavaScript error 级日志。
- 前端产物总大小由 87,625 增至 93,174 字节（约增加 5.4 KiB），主要来自结构、样式和文案。没有测出或声称硬件解码、CPU、发热、延迟方面的提升。

范围与版本
本目录是基于 0.1.1 的 0.1.2 界面迭代：网页包版本 0.1.2，接收端和盒子业务代码保持 0.1.1。本次没有重新发布接收端二进制或固件。前端构建包只用于工程集成，不是可以直接刷入 F50 的安装包。旧的 0.1.1 程序包不会自动包含这次界面变化。
本轮未重新执行与界面无关的 Kotlin/盒子测试；之前结果及未解决风险继续见 docs/AUDIT-0.1.1.md。
设备信息沿用用户说明：F50 B13、2022 AMD Model 3 Performance、iPhone 15 Pro / iOS 27.2。尚未实机验证。B13 兼容和安装路径仍需单独处理，不能因界面通过本机测试而视为可刷机。

上车验收重点
停车后从驾驶座检查中文是否一眼读清、最远侧按钮是否易点；在日光和夜间各检查一次。对比 CarPlay 内容大小各档位，确认地图道路名、转向提示、来电与音乐页面布局。验证浏览器窗口/无边框切换后无裁切，手指点击仍对准画面。确认进入设置、返回画面以及断连恢复期间提示清楚。
